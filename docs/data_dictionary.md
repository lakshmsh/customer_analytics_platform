# Data Dictionary: Customer Analytics Platform

This document details the schema, data types, business descriptions, and constraints for all raw datasets and processed feature stores.

---

## 1. Raw Dataset: Telco Customer Churn (`data/raw/telco_customer_churn.csv`)

- **Domain**: Contractual Subscription Telecommunications
- **Grain**: 1 row per customer (7,043 rows)
- **Primary Key**: `customerID`

| Column Name | Data Type | Nullable | Example Values | Description |
| :--- | :--- | :--- | :--- | :--- |
| `customerID` | string | No | `7590-VHVEG`, `5575-GNVDE` | Unique alphanumeric customer identifier. |
| `gender` | string | No | `Male`, `Female` | Customer gender. |
| `SeniorCitizen` | integer | No | `0`, `1` | Indicator if the customer is 65 years or older. |
| `Partner` | string | No | `Yes`, `No` | Indicator if customer has a spouse / partner. |
| `Dependents` | string | No | `Yes`, `No` | Indicator if customer lives with dependents. |
| `tenure` | integer | No | `1`, `34`, `72` | Number of months the customer has stayed with the company. |
| `PhoneService` | string | No | `Yes`, `No` | Whether customer subscribes to landline phone service. |
| `MultipleLines` | string | No | `Yes`, `No`, `No phone service`| Whether customer has multiple phone lines. |
| `InternetService` | string | No | `DSL`, `Fiber optic`, `No` | Customer's internet service provider technology. |
| `OnlineSecurity` | string | No | `Yes`, `No`, `No internet service`| Whether customer subscribes to online security add-on. |
| `OnlineBackup` | string | No | `Yes`, `No`, `No internet service`| Whether customer subscribes to online cloud backup. |
| `DeviceProtection` | string | No | `Yes`, `No`, `No internet service`| Whether customer has device insurance/protection. |
| `TechSupport` | string | No | `Yes`, `No`, `No internet service`| Whether customer has dedicated technical support. |
| `StreamingTV` | string | No | `Yes`, `No`, `No internet service`| Whether customer uses streaming TV service. |
| `StreamingMovies` | string | No | `Yes`, `No`, `No internet service`| Whether customer uses streaming movie service. |
| `Contract` | string | No | `Month-to-month`, `One year`, `Two year` | Contractual billing commitment terms. |
| `PaperlessBilling` | string | No | `Yes`, `No` | Whether bill is delivered digitally. |
| `PaymentMethod` | string | No | `Electronic check`, `Mailed check`, `Bank transfer (automatic)`, `Credit card (automatic)` | Selected billing payment method. |
| `MonthlyCharges` | float | No | `29.85`, `56.95`, `103.20` | Amount charged to customer monthly (USD). |
| `TotalCharges` | float (str raw) | Yes (11 blanks) | `29.85`, `1889.50` | Total cumulative charges incurred across tenure. |
| `Churn` | string | No | `Yes`, `No` | Target variable: Did customer terminate service within last month? |

## 2. Raw Dataset: Online Retail II (`data/raw/online_retail_II.xlsx`)

- **Domain**: Non-contractual E-commerce Transactions (UK registered online retailer, 2009–2011)
- **Grain**: 1 row per invoice line item (~1,067,371 rows across 2 sheets)
- **Sheets**: `Year 2009-2010`, `Year 2010-2011`

| Column Name | Data Type | Nullable | Example Values | Description |
| :--- | :--- | :--- | :--- | :--- |
| `Invoice` | string | No | `489434`, `C489449` | 6-digit invoice number. If code starts with letter `C`, it represents a cancellation. |
| `StockCode` | string | No | `85048`, `79323P`, `POST` | 5-digit integral or alphanumeric product code. |
| `Description` | string | Yes (~4k missing)| `15CM CHRISTMAS GLASS BALL 20 LIGHTS` | Product name and descriptive catalog title. |
| `Quantity` | integer | No | `12`, `-24` | Units purchased per line item. Negative quantities indicate cancellations or damaged stock. |
| `InvoiceDate` | datetime | No | `2009-12-01 07:45:00` | Date and time when the transaction was generated. |
| `Price` | float | No | `6.95`, `0.0` | Product unit price in GBP (£). |
| `Customer ID` | float / int | Yes (~240k missing) | `13085.0`, `17850.0` | 5-digit unique customer identifier. |
| `Country` | string | No | `United Kingdom`, `Germany`, `France` | Country of customer residence. |

## 3. Processed Feature Store: Customer Features (`data/processed/customers_features.parquet`)

- **Grain**: 1 row per unique customer
- **Primary Key**: `customer_id`

| Feature Name | Type | Description | Formula / Source |
| :--- | :--- | :--- | :--- |
| `customer_id` | string / int | Canonical customer identifier. | `Customer ID` from transactions |
| `recency_days` | integer | Days elapsed between customer's latest purchase and cutoff date. | $T_{\text{cutoff}} - \max(\text{InvoiceDate})$ |
| `frequency_orders` | integer | Total distinct purchase orders placed by the customer. | $\text{count}(\text{distinct Invoices})$ |
| `monetary_total` | float | Total net revenue generated by the customer. | $\sum (\text{Quantity} \times \text{Price})$ |
| `avg_basket_value` | float | Average monetary value per invoice. | $\text{monetary\_total} / \text{frequency\_orders}$ |
| `avg_basket_size` | float | Average item quantity per invoice. | $\text{total\_quantity} / \text{frequency\_orders}$ |
| `tenure_days` | integer | Days between first and latest purchase. | $\max(\text{InvoiceDate}) - \min(\text{InvoiceDate})$ |
| `unique_items_count` | integer | Number of distinct product SKUs purchased. | $\text{count}(\text{distinct StockCode})$ |
| `cancellation_rate` | float | Ratio of cancelled orders to total orders. | $\text{count}(\text{cancelled}) / \text{frequency\_orders}$ |
| `purchase_interval_mean` | float | Average days elapsed between successive orders. | $\text{mean}(\Delta t_{\text{orders}})$ |
| `purchase_interval_std` | float | Standard deviation of order spacing (regularity). | $\text{std}(\Delta t_{\text{orders}})$ |
| `is_churned` | integer | Binary churn target (1 if inactive for $\ge 90$ days, else 0). | $\mathbb{I}(\text{recency\_days} \ge 90)$ |
| `rfm_score` | string | Combined RFM quintile rating. | Concatenation of $R, F, M$ scores (1–5) |
| `segment` | string | Behavioral cluster cohort name. | Assigned by K-Means persona profile |

## 4. Time Series Store: Daily Demand & Revenue (`data/processed/daily_demand_revenue.parquet`)

- **Grain**: 1 row per calendar date

| Feature Name | Type | Description |
| :--- | :--- | :--- |
| `date` | date | Transaction calendar date (`YYYY-MM-DD`). |
| `daily_revenue` | float | Total sum of net sales (£). |
| `daily_orders` | integer | Total count of distinct invoices. |
| `daily_items_sold` | integer | Total quantity of items sold. |
| `unique_buyers` | integer | Number of distinct active customers. |
| `is_weekend` | integer | 1 if Saturday or Sunday, else 0. |
| `day_of_week` | integer | 0 (Monday) to 6 (Sunday). |
| `month` | integer | Calendar month (1–12). |
